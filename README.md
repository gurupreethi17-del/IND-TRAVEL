## 🚀 3. Five Core Priority Modules

### 🧠 Priority 1: AI Smart Trip Planner (`#planner`)
- Dynamic itinerary synthesis across destinations (Hyderabad, Agra, Varanasi, Hampi, Jaipur, Kerala, Ladakh, etc.).
- Configurable days (1–7 days), budget tiers (Backpacker, Balanced, Luxury), traveler counts, and interests.
- Day-by-day morning, afternoon, and evening breakdowns with crowd-avoidance schedules.
- Estimated INR budget allocations, authentic local culinary trails, and printable PDF export.

### 🏛 Priority 2: AI Heritage & Cultural Scanner (`#scanner`)
- Futuristic camera HUD with scanning laser grid, corner reticles, and ASI 99.4% match confidence indicators.
- Instant architectural dossier: Era, Dynasty, Architectural Style, Cultural Importance, and Hidden Secrets.
- **Text-to-Speech Audio Guide** via Web Speech API with speed adjustment (1.0x, 1.25x) and audio waveform animation.

### 🌐 Priority 3: Multilingual AI Travel Assistant (`#assistant`)
- Speech-to-Text (STT) voice input + spoken voice response toggle.
- Full multilingual coverage: **10 Indian Languages** (Hindi, Telugu, Tamil, Kannada, Malayalam, Bengali, Marathi, Gujarati, Punjabi, English) + **3 Global Languages** (French, German, Spanish).
- Intelligent travel knowledge: transit routes, temple dress codes, food safety, and train RAC/WL guidelines.

### 🛡 Priority 4: Smart Tourist Safety Guardian (`#safety`)
- Dynamic live safety status (`🟢 SAFE`) with GPS coordinates detection.
- High-visibility **Emergency SOS Distress Button** triggering a 3-step prototype activation sequence:
  1. GPS Coordinates Captured
  2. Designated Contacts Notified
  3. Nearest Police Post and Trauma Care Hospital Identified
- 24x7 verified Indian emergency hotlines (112, 1363, 1090, 108).
- One-touch live location sharing encrypted link generator.

### 📊 Priority 5: Smart Tourism Intelligence Dashboard (`#intelligence`)
- Prototype demonstration data for tourism authorities and crowd management.
- Live crowd status monitors: `🟢 Normal`, `🟡 Moderate`, `🔴 High`.
- **Dynamic Crowd Diversion AI Simulation**: Automatically alerts tourists during peak congestion to visit alternative scenic vantage points (e.g. Mehtab Bagh instead of Taj East Gate) and triggers electric shuttle dispatch notifications.
- Chart.js visual analytics: Hourly Footfall vs Sustainable Capacity, Regional Flow Share, and Tourist Sentiment Index.

## 💻 5. How to Run Locally

### Option A: One-Click Windows Launcher (Recommended)
Double-click **`run_app.bat`**. It will start the lightweight Python server and automatically open the application in your default web browser at `http://localhost:3000`.

### Option B: Python Terminal Command
```bash
python server.py
# or
py server.py
```

### Option C: Direct Browser Opening
Simply double-click or open `index.html` directly in Chrome, Edge, Safari, or Firefox. All assets, stylesheets, scripts, and libraries will load seamlessly!
